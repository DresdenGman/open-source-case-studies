# Open-Source Case Studies

Selected engineering case studies documenting my contributions to open-source scientific Python projects: the problems investigated, the implementation decisions, the testing, and the upstream review process.

- [SALib — Six Pull Requests, Six Merged](salib-case-study.md): bug fixes and statistical-correctness work in the SALib sensitivity-analysis library.
- [StatsForecast — Three Pull Requests, Three Merged](statsforecast-case-study.md): prediction intervals, performance, and packaging work in Nixtla's StatsForecast.

The upstream pull requests linked from each case study are the primary record; these documents explain and organize that record.
